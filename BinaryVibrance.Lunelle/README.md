# BinaryVibrance.Lunelle

A synthesizer for .NET games, on [Sirrow](https://github.com/AtomicBlom/Sirrow)'s mixer: a 16-operator chip with patches as
data, samples and drum kits, and music written as code or as files (`lunelle-song/2`, `lunelle-patch/1`), played by a
sequencer on the audio clock. The package carries the music generator, which makes a project's song and patch files
into C# as it builds.

[The guide](https://github.com/AtomicBlom/Lunelle/blob/master/docs/synth.md) covers the API.
